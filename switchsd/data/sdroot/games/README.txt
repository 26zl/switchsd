Put game files here: .nsp, .nsz, .xci or .xcz (base games, updates and DLC).
On a computer, `switchsd.py games FILE...` copies them here. FAT32 holds no file of 4 GB or more,
so it stores such a file as a folder of parts, which the console reads as one file.
Install them with DBI (Browse SD card > games) or Goldleaf, to the SD card.
Delete the files here once they are installed; the installed copy lives in emuMMC/RAW1/Nintendo.
